# 操作說明

這份文件涵蓋編輯器的完整操作細節（快捷鍵、每種區塊的行為、已知限制等）。想快速上手的話，先看根目錄的 [README](../README.md) 就好，這裡是給想深入了解每個功能行為的人參考。

## 編輯區操作

- 標題（筆記檔名）可直接點擊編輯：按 `Enter` 或點擊其他地方確認重新命名，按 `Esc` 取消還原。改成已存在的名稱會顯示錯誤並還原。
- 標題下方會顯示這篇筆記的更新時間（例如「更新於 3 小時前」），依檔案的實際修改時間換算，載入筆記時計算一次；正在編輯時會改顯示「編輯中…」/「已儲存 HH:MM:SS」等即時狀態。
- `Enter`：依游標位置切開目前區塊的文字（含粗體/斜體等行內格式）。游標在文字最前面時，會在目前區塊**前面**插入一個新空白區塊，原內容與子項目不受影響；游標在文字結尾或中間時，游標後面的文字（若有）會移到**後面**新插入的區塊，原區塊保留游標前的文字與所有子項目（一般清單／編號清單／待辦清單會延續同型態）。
- `Tab` / `Shift+Tab`：將區塊縮排為子項目 / 取消縮排。
- `Backspace`（區塊內容為空時）：刪除該區塊。
- `↑` / `↓`：將游標移到上一個 / 下一個區塊（依樹狀展開順序，摺疊的子項目不會被跳到）。若上一個/下一個區塊是表格，會移到表格的第一列（`↓`進入）或最後一列（`↑`進入）的第一欄；若是程式碼區塊，會移到內容的開頭（`↓`進入）或結尾（`↑`進入）。
- 表格最上面一列的儲存格、或程式碼區塊內容的第一行，若已經是筆記裡最前面的區塊（前面沒有其他區塊可以跳），按 `↑` 會在它上方新增一個空白段落並把游標移過去，讓你可以直接在表格/程式碼區塊上方插入內容（不需要切到「檢視原始碼」手動編輯）。
- `Ctrl+↑` / `Ctrl+↓`：將區塊本身上移 / 下移（調整順序，游標留在原區塊）。
- 點擊區塊左側的摺疊箭頭：摺疊 / 展開子項目。
- 在區塊開頭輸入 `#`～`######` 加空白：將該區塊轉換為對應層級的標題。
- 滑鼠移到區塊上會出現「Aa」格式按鈕，可切換標題 1/2/3、引用、編號清單、待辦清單、一般文字、表格、插入圖片、程式碼、提示框、分隔線。
- `Ctrl+Alt+1` / `Ctrl+Alt+2` / `Ctrl+Alt+3`：將目前區塊設為標題 1/2/3；`Ctrl+Alt+0`：還原為一般文字。
- 待辦清單項目可直接點擊前方核取方塊切換完成狀態（完成後套用刪除線樣式）。
- 在一般段落／清單項目裡直接打 `[ ] ` 或 `[x] `（含結尾空白，前面可以有或沒有 `- `）會立即就地轉成待辦清單項目，不需要透過格式選單，比照打 `# ` 即時變標題、打 `---` 即時變分隔線的慣例。

## 行內格式與浮動工具列

- 選取一段文字時會出現浮動工具列，可套用粗體、斜體、刪除線、醒目提示、行內程式碼、連結；也可用快捷鍵 `Ctrl+B` / `Ctrl+I` / `Ctrl+Shift+X`。已套用的格式會讓浮動工具列上對應的按鈕反白標示，方便確認目前選取範圍套用了哪些格式。
- 浮動工具列的「H1」「H2」「H3」「"」（引用）按鈕：選取文字後點擊，會把選取範圍所在的**整個區塊**轉換為對應層級的標題或引用（原有的行內格式會保留）。若該區塊目前已經是點擊的目標型態，再點一次會取消、轉回一般文字。
- 浮動工具列的項目符號清單按鈕：把選取範圍所在的整個區塊轉換為一般文字（項目符號清單）型態。
- 浮動工具列的清除格式按鈕（橡皮擦圖示）：把粗體/斜體/刪除線/醒目提示/行內程式碼/連結等行內格式全部清除，只留下純文字；區塊型態與未選取的其餘文字不受影響。

## 連結

純點擊連結文字只會把游標定位在該處（不會跳頁，維持編輯安全），滑鼠移到連結上並停留約 0.5 秒或游標移進連結內會浮出一張小卡片，顯示完整網址並提供「開啟」「編輯」「移除」三個按鈕；也支援 `Ctrl+點擊`（Mac 為 `Cmd+點擊`）直接在新分頁開啟連結。

插入連結支援快捷鍵 `Ctrl+K`（Mac 為 `Cmd+K`）：選取一段文字後按下，會跳出輸入框讓你輸入網址；如果游標本來就在既有連結內，按下後會改為開啟編輯網址的輸入框（預填目前網址），不會直接移除連結。直接打一段網址（`http://`、`https://` 或 `www.` 開頭）、緊接著按 `Enter`，網址會自動變成可點擊的連結。

## 搜尋與復原

- `Ctrl+F`：開啟「筆記內搜尋」搜尋列（僅搜尋目前這篇筆記，不是跨筆記的全文搜尋），輸入文字即醒目提示所有符合結果並顯示筆數（如 `1/4`）；可切換「Aa」區分大小寫、「.*」正規表示式；上下箭頭或 `Enter`／`Shift+Enter` 在符合結果間跳轉；點擊切換取代按鈕（⇄）展開取代列，可「取代」單一筆或「全部取代」。
- `Ctrl+Z`：復原上一步修改，可連續復原到剛開啟此筆記時的狀態；`Ctrl+Shift+Z` 或 `Ctrl+Y`：取消復原。復原/取消復原的範圍僅限於目前開啟的這篇筆記。

## 檢視原始碼與複製

- 右上角「檢視原始碼」按鈕：切換為可直接檢視、貼上、編輯完整 Markdown 原始碼的模式，切回區塊模式時會重新解析成區塊。切換時游標位置會盡量延續（對到同一個區塊，不保證精準到確切字元位置）。
- 右上角「複製原始碼」按鈕：一鍵把整篇筆記目前的 Markdown 原始碼複製到剪貼簿。這兩顆按鈕會固定顯示在畫面右上角，捲動筆記內容時仍維持可見、可操作。
- **貼上多行內容自動拆成區塊**：貼上一段多行 Markdown 文字時，系統會自動拆解成對應的標題／清單／表格／段落等區塊。
- **選取範圍橫跨多個區塊時複製**：選取範圍橫跨多個區塊時，`Ctrl+C` 複製到剪貼簿的內容會是乾淨的 Markdown 文字，不會遺漏內容、也不會混入編輯器介面文字。目前選取範圍本身仍受限於瀏覽器對多個獨立可編輯區域的限制，暫時無法用滑鼠拖曳或 `Shift+方向鍵` 跨區塊延伸選取。

## 表格

表格（GFM `| ... |` 語法）會正確渲染成真正的表格，每個儲存格可直接點擊編輯文字（含粗體/斜體等行內格式）。

- **新增表格**：滑鼠移到任一區塊上點擊「Aa」格式按鈕，選「表格」即可把該區塊轉成一個 2×2 的空表格。
- **新增/刪除列欄**：表格最後一列下方有「+ 新增列」；表頭最後一欄右邊有「+」新增欄；每個資料列前面、每個表頭儲存格右上角都有一顆「×」可刪除該列/欄（表頭本身不能刪，欄位至少會保留 1 欄）。
- 儲存格之間可用 `Tab` / `Shift+Tab` 左右移動；在最後一格按 `Tab` 會自動新增一列並移入。
- 儲存格內按 `↑` / `↓` 會移到同一欄的上一列 / 下一列。
- **儲存格內的打勾清單**：如果儲存格內容剛好是打勾清單語法（`[ ]`／`[x]`／`[X]`，前面可以有或沒有 `-`，後面可以接文字），會呈現成一個可直接點擊的核取方塊，而不是顯示原始的方括號文字；點擊後會把內容正規化寫回 `- [x]` 或 `- [ ]`（保留後面的文字），方便用表格做像「待辦事項清單」這種帶欄位資訊的核取表。也可以直接在儲存格最前面打 `[]`（或 `[x]`）再按空白鍵，會立即就地轉成核取方塊、游標留在原本文字的最前面可以直接接續編輯（儲存格若已有文字，會變成核取方塊後面的標籤文字），不需要先存檔再重新整理才會生效。
- **還原核取方塊**：核取方塊上（或核取方塊後方標籤文字剛好是空的時候）按 `Backspace`／`Delete`，會把整個儲存格清空、還原成一般可編輯的空白文字儲存格；如果標籤文字還有內容，游標停在文字裡按 `Backspace` 則是正常刪字，不會誤刪整格。
- 表格儲存格內僅支援單行文字與行內格式（打勾清單語法是例外），不能在儲存格裡再放其他清單、標題等區塊；目前無法從編輯器裡直接刪除整個表格區塊，也沒有欄位寬度拖曳調整；要移除整個表格或調整既有列/欄順序，暫時只能切到「檢視原始碼」手動編輯。
- 兩個表格區塊只要彼此相鄰，存檔時系統都會自動在兩者之間補一行真正的空白行，確保重新載入時仍會被解析成兩個獨立的表格、不會合併——這是系統自動保證的，不需要自己維護。

## 圖片

三種方式插入圖片：直接貼上剪貼簿裡的圖片（`Ctrl+V`）、把圖片檔案拖放到編輯區、或用「Aa」格式按鈕選「插入圖片」。圖片會上傳並存成跟目前這篇筆記**同一個資料夾**下的檔案，僅接受 `png`／`jpg`／`jpeg`／`gif`／`webp`，單檔大小上限 10MB。滑鼠移到圖片上會出現「×」可刪除該圖片區塊（僅移除筆記裡的參考，不會刪除磁碟上的圖片檔案）。

圖片存在跟筆記同一個資料夾，不是獨立附屬資料夾；「搬移」筆記到別的資料夾時，圖片檔案不會跟著搬（筆記裡的圖片參考會失效），「刪除」筆記也不會一併刪除同資料夾的圖片，需自行清理。

## 分隔線

獨立一行、由 3 個以上 `-`（或 `*`、`_`）組成的 Markdown 分隔線語法，會解析成一條視覺上的分隔線區塊；直接打 `---` 也會即時轉換。也可以透過「Aa」格式按鈕選「分隔線」把既有區塊轉換成分隔線。不支援「文字行緊接 `---` 會變成標題」的 Setext 標題語意。

## 程式碼區塊

滑鼠移到區塊上點「Aa」格式按鈕選「程式碼」，即可把該區塊轉成一個淡色背景、等寬字型的程式碼區塊。編輯焦點在區塊內時，右上角會出現一個語言下拉選單（純粹當作標記，目前沒有語法高亮效果）。`Tab` 鍵在程式碼區塊內是瀏覽器預設行為（不會輸入縮排字元）。

## 提示框（Callout）

滑鼠移到區塊上點「Aa」格式按鈕選「提示框」，即可把該區塊轉成一個帶顏色背景的提示框，可切換 5 種種類：備註／提示／重要／警告／注意。儲存的 Markdown 語法採用 GitHub Flavored Markdown 的 Alerts 慣例（`> [!NOTE]` 等）。提示框內文的方向鍵上下移動維持瀏覽器原生的游標移動行為，沒有比照表格/程式碼區塊做「移到邊界時跳出至相鄰區塊」的特殊處理；要離開提示框，可清空內容後按 `Backspace` 刪除該區塊，或直接點擊筆記其他地方。

## 表格／圖片／程式碼區塊／提示框／分隔線的共通行為

這五種區塊本身沒有游標可以按 `Enter` 加空行，區塊正上方會有一個淡化顯示、橫跨整個區塊寬度的「+」，滑鼠移到那一整條範圍會變成清楚可見，點擊即可在該區塊前插入一個空白段落並把游標移過去。

如果這類區塊是筆記最底下的區塊，編輯區會固定多顯示一行空白、可直接點擊輸入的段落；這個空白段落只在畫面上輔助編輯，只要沒有實際輸入任何內容，存檔時就不會留在 `.md` 檔案裡。

## 字級調整（舊筆記相容性）

浮動工具列已移除自訂文字大小（原本的「小/一般/大/特大」四級字級調整）的功能，改由「一般文字／標題 3／標題 2／標題 1」四級大小涵蓋。舊筆記若原本就含有字級調整（`<span style="font-size:...">`），仍會正常顯示；只是編輯器不再提供入口建立新的字級調整。若把含有舊字級調整的範圍轉換為標題，系統會一併清除該字級調整（避免標題文字大小不一致），但轉換為其他型態（引用、清單等）不會清除。

## 已知限制

- 大綱區塊對應標題、清單（含巢狀）、表格、圖片、程式碼區塊、提示框、分隔線、一般段落等 Markdown 語法；若筆記檔案含有其他尚未支援的 Markdown 語法，載入時會以純文字段落顯示，儲存時原樣保留內容，但不會被區塊化編輯。
- 程式碼區塊目前沒有語法高亮；開頭/結尾的圍欄記號那一行必須整行只有 ` ``` `，前後夾雜其他文字則不會被辨識成程式碼區塊。
- 不提供跨筆記的全文搜尋（需要建立索引），只有 `Ctrl+F` 這種侷限在「目前這篇筆記」內的搜尋/取代；也不提供版本歷史、多人協作等功能。
- `Ctrl+F` 搜尋/取代的範圍涵蓋一般段落、標題、清單、引用、程式碼區塊與提示框，但不含表格儲存格與圖片替代文字。程式碼區塊內的符合結果因為輸入元件本身的限制，無法像其他區塊一樣同時標示「所有」符合結果，跳轉到程式碼區塊裡的符合結果時會改用橘色外框標示整個程式碼區塊。
- 貼上多行內容時只讀取剪貼簿的純文字（`text/plain`），來源如果是網頁或 Word 等透過剪貼簿 HTML 呈現的格式，不會被保留。
- 醒目提示是以 `==文字==` 語法存進 `.md` 檔案，這是部分 Markdown 方言（例如 Obsidian）支援的慣例語法、非 CommonMark 標準核心語法；用不支援這個語法的檢視器開啟，會直接看到原始的 `==` 符號。
- 選取範圍橫跨多個區塊時，複製（`Ctrl+C`）的結果已正確處理，但選取範圍本身目前只能靠原生瀏覽器行為產生，暫時無法用滑鼠拖曳或鍵盤跨區塊延伸選取範圍。

## 開啟一篇筆記

開啟一篇筆記後，網址列會記錄該筆記的路徑；重新整理頁面會自動展開對應資料夾並恢復到原本開啟的那篇筆記。

## Windows 7 相容性

本專案的相依套件（Flask 2.0.3 及其依賴）皆為純 Python 實作、無需編譯，已在實際 Windows 7 機器上安裝並實際使用中，確認可正常運作。前端圖示大多為手繪的單色線條 SVG（不使用任何表情符號），避免在缺乏完整彩色表情符號字型的舊瀏覽器上顯示成黑白線框或方框；例外是「新增資料夾」「新增筆記」與樹狀索引裡每個節點的資料夾/筆記圖示，這幾個是一般 PNG 點陣圖，不依賴表情符號字型。
