# 本機知識筆記編輯器

一個完全在本機執行的筆記工具：左側是資料夾樹狀索引，右側是類似 [Outline](https://www.getoutline.com/) 的大綱式區塊編輯器。所有筆記都以純 Markdown（`.md`）檔案存在你自己的電腦裡——沒有雲端帳號、沒有資料庫，開一個瀏覽器分頁就能用。

## 為什麼會有這個專案

想要一個「打開就能寫」的筆記工具，但：

- 不想把筆記交給雲端服務保管；
- 希望筆記本身就是一般文字檔案，日後想搬到別的工具、用 Git 做版本控制、或直接用文字編輯器打開，都不會被綁住；
- 喜歡 Notion / Outline 那種「打字就變成標題／清單／表格」的大綱式編輯體驗，但不需要它們的協作、雲端同步等重量級功能。

## 功能特色

- **大綱式區塊編輯**：標題、清單（含巢狀縮排）、表格、圖片、程式碼區塊、提示框（callout）、分隔線……都是可以拖曳排序、上下移動的獨立區塊，操作手感接近 Notion / Outline。
- **純 Markdown 儲存**：所有內容都是標準（或接近標準）的 Markdown 語法，存成 `.md` 檔案，隨時可以切換到「檢視原始碼」模式直接編輯純文字。
- **完全離線、資料在自己手上**：伺服器只綁定在 `127.0.0.1`，不對外部網路開放；筆記存放路徑可自訂，方便放進自己的雲端同步資料夾或 Git 專案。
- **筆記內搜尋與取代**、**復原/取消復原**、**連結卡片**、**貼上內容自動拆解成區塊**等一般筆記工具會有的體驗細節。
- 可在 **Windows 7** 上安裝執行（詳見下方相容性說明）。

## 快速開始

需求：Python 3.8 以上、現代瀏覽器（Chrome、Edge、Firefox 等）。

```bash
cd notes-editor
pip install -r requirements.txt
python app.py
```

啟動後於瀏覽器開啟 `http://127.0.0.1:5000` 即可開始使用。

預設會在 `notes-editor/notes/` 建立筆記資料夾；也可以用環境變數指定其他位置：

```bash
set NOTES_ROOT=D:\MyNotes
set PORT=5051
python app.py
```

## Windows 7 相容性

相依套件（Flask 及其依賴）皆為純 Python 實作、無需編譯，已在實際 Windows 7 機器上安裝並使用中。前端圖示以手繪單色線條 SVG 為主，避免舊瀏覽器缺乏彩色表情符號字型時顯示異常。
