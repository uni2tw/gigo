# 本機知識筆記編輯器

本機可執行的知識整理工具：左側樹狀索引瀏覽本機筆記資料夾，右側以類似 Outline
的大綱式編輯器撰寫內容，所有筆記以 Markdown（`.md`）純文字格式儲存在本機檔案
系統，不需要網路連線，也不含全文搜尋功能。

## 系統需求

- Python 3.8（Windows 7 上官方最後支援的 Python 版本；本專案的相依套件皆為
  純 Python 實作，不需編譯，理論上可在更新的 Python 版本上執行）。
- 現代瀏覽器（Chrome、Edge、Firefox 等，含可於 Win7 上安裝的版本）。

## 安裝

```bash
cd notes-editor
pip install -r requirements.txt
```

## 啟動

```bash
python app.py
```

啟動後於瀏覽器開啟 `http://127.0.0.1:5000`。伺服器僅綁定在
`127.0.0.1`（僅本機可存取），不會對外部網路開放。

## 筆記根目錄設定

- 預設使用專案目錄下的 `notes/` 資料夾，若不存在會自動建立。
- 可透過環境變數 `NOTES_ROOT` 指定其他路徑：

```bash
set NOTES_ROOT=D:\MyNotes
python app.py
```

- 可透過環境變數 `PORT` 指定其他埠號（預設 `5000`），方便在同一台機器上另外開一個測試用的執行個體，不會跟正在使用的既有伺服器衝突：

```bash
set PORT=5051
python app.py
```

## 操作說明

- **左側樹狀索引**：點擊資料夾可展開/收合，並將其設為「目前操作目標」；
  點擊上方「新增資料夾」「新增筆記」圖示按鈕會在目前選取的資料夾下新增資料夾或筆記。
  滑鼠移到節點上時，最右側會出現「⋮」按鈕，點擊可開啟操作選單：筆記節點為「重新命名／搬移／刪除」；資料夾節點最前面多一項「新文件」（直接在該資料夾下新增筆記，新增後會自動展開該資料夾），「刪除」則在資料夾底下（含子資料夾）還有筆記時反灰無法點擊，需清空後才能刪除。也可直接按住節點拖曳到某個資料夾上放開，快速搬移過去（拖曳資料夾到它自己的子資料夾底下會被拒絕並提示錯誤），或拖到樹狀索引的空白處放開，搬回最外層。同一層級中資料夾一律排在筆記檔案前面；資料夾右側若底下（含子資料夾）有筆記，會顯示筆記總數的徽章。
- **右側編輯區**：點擊筆記節點後於右側編輯。
  - 標題（筆記檔名）可直接點擊編輯：按 `Enter` 或點擊其他地方確認重新命名，按 `Esc` 取消還原。改成已存在的名稱會顯示錯誤並還原。
  - 標題下方會顯示這篇筆記的更新時間（例如「更新於 3 小時前」），依檔案的實際修改時間換算，載入筆記時計算一次；正在編輯時會改顯示「編輯中…」/「已儲存 HH:MM:SS」等即時狀態。
  - `Enter`：依游標位置切開目前區塊的文字（含粗體/斜體等行內格式）。游標在文字最前面時，會在目前區塊**前面**插入一個新空白區塊，原內容與子項目不受影響；游標在文字結尾或中間時，游標後面的文字（若有）會移到**後面**新插入的區塊，原區塊保留游標前的文字與所有子項目（一般清單／編號清單／待辦清單會延續同型態）。
  - `Tab` / `Shift+Tab`：將區塊縮排為子項目 / 取消縮排。
  - `Backspace`（區塊內容為空時）：刪除該區塊。
  - `↑` / `↓`：將游標移到上一個 / 下一個區塊（依樹狀展開順序，摺疊的子項目不會被跳到）。若上一個/下一個區塊是表格，會移到表格的第一列（`↓`進入）或最後一列（`↑`進入）的第一欄；若是程式碼區塊，會移到內容的開頭（`↓`進入）或結尾（`↑`進入）。
  - 表格最上面一列的儲存格、或程式碼區塊內容的第一行，若已經是筆記裡最前面的區塊（前面沒有其他區塊可以跳），按 `↑` 會在它上方新增一個空白段落並把游標移過去，讓你可以直接在表格/程式碼區塊上方插入內容（不需要切到「檢視原始碼」手動編輯）。
  - `Ctrl+↑` / `Ctrl+↓`：將區塊本身上移 / 下移（調整順序，游標留在原區塊）。
  - 點擊區塊左側的摺疊箭頭：摺疊 / 展開子項目。
  - 在區塊開頭輸入 `#`～`######` 加空白：將該區塊轉換為對應層級的標題。
  - 滑鼠移到區塊上會出現「Aa」格式按鈕，可切換標題 1/2/3、引用、編號清單、待辦清單、一般文字。
  - `Ctrl+Alt+1` / `Ctrl+Alt+2` / `Ctrl+Alt+3`：將目前區塊設為標題 1/2/3；`Ctrl+Alt+0`：還原為一般文字。
  - 待辦清單項目可直接點擊前方核取方塊切換完成狀態（完成後套用刪除線樣式）。
  - 選取一段文字時會出現浮動工具列，可套用粗體、斜體、刪除線、醒目提示、行內程式碼、連結；也可用快捷鍵 `Ctrl+B` / `Ctrl+I` / `Ctrl+Shift+X`。已套用的格式（粗體/斜體/刪除線/醒目提示/行內程式碼/連結）會讓浮動工具列上對應的按鈕反白標示，方便確認目前選取範圍套用了哪些格式。
  - 浮動工具列的「H1」「H2」「H3」「"」（引用）按鈕：選取文字後點擊，會把選取範圍所在的**整個區塊**轉換為對應層級的標題或引用（原有的行內格式會保留），不需要離開選取狀態去記快捷鍵或另外開啟「Aa」選單。若該區塊目前已經是點擊的目標型態，再點一次會取消、轉回一般文字（項目符號清單），效果等同粗體/斜體等按鈕「再按一次取消」的邏輯。若選取範圍內含有舊筆記留下的字級調整（見下方已知限制），轉換為標題時會一併清除該字級調整，避免標題裡出現大小不一致的文字。
  - 浮動工具列的項目符號清單按鈕：選取文字後點擊，會把選取範圍所在的整個區塊轉換為一般文字（項目符號清單）型態，跟「Aa」選單裡的「一般文字」是同一件事，只是多一個浮動工具列上的快速入口。
  - 浮動工具列的清除格式按鈕（橡皮擦圖示）：選取一段已套用格式的文字並點擊，會把粗體/斜體/刪除線/醒目提示/行內程式碼/連結/字級調整等行內格式全部清除，只留下純文字；區塊型態與未選取的其餘文字不受影響。
  - 「Aa」格式選單開啟時，會把符合區塊目前型態（含標題層級）的選項反白標示，方便確認目前是什麼格式。
  - **連結的開啟／編輯／移除**：純點擊連結文字只會把游標定位在該處（不會跳頁，維持編輯安全），滑鼠移到連結上並停留約 0.5 秒（單純掃過、沒有要停留的話不會觸發，避免滑鼠移動路徑經過連結時卡片一直閃現）或游標移進連結內（此為立即顯示，不套用停留延遲）會浮出一張小卡片，顯示完整網址並提供「開啟」（新分頁開啟）、「編輯」（跳出輸入框、預填目前網址供修改）、「移除」（×，只拿掉連結格式、保留文字）三個按鈕；也支援 `Ctrl+點擊`（Mac 為 `Cmd+點擊`）直接在新分頁開啟連結，不需要先叫出小卡片。按住 `Ctrl`／`Cmd` 期間，連結會顯示一般連結常見的指標游標樣式、且不會彈出小卡片，提示「這裡準備要開啟」，避免跟編輯用的小卡片混淆；放開後恢復原本的文字游標與小卡片行為。
  - `Ctrl+F`：開啟「筆記內搜尋」搜尋列（僅搜尋目前這篇筆記，不是跨筆記的全文搜尋），輸入文字即醒目提示所有符合結果並顯示筆數（如 `1/4`）；可切換「Aa」區分大小寫、「.*」正規表示式；上下箭頭或 `Enter`／`Shift+Enter` 在符合結果間跳轉，跳轉到已收合的區塊內容時會自動展開；點擊切換取代按鈕（⇄）展開取代列，輸入取代文字後可「取代」目前這一筆（取代後只影響符合結果本身，不影響同區塊內其餘的粗體/斜體等格式），或「全部取代」一次取代所有符合結果（整個「全部取代」動作只計入復原歷史的一步，一次 `Ctrl+Z` 即可全部復原）；按 `Esc` 或關閉按鈕（×）關閉搜尋列，切換到其他筆記時也會自動關閉。
  - `Ctrl+Z`：復原上一步修改，可連續復原到剛開啟此筆記時的狀態；`Ctrl+Shift+Z` 或 `Ctrl+Y`：取消復原。復原/取消復原的範圍僅限於目前開啟的這篇筆記，切換到其他筆記後會重新計算。
  - 右上角「檢視原始碼」按鈕（`</>` 圖示）：切換為可直接檢視、貼上、編輯完整 Markdown 原始碼的模式，切回區塊模式時會重新解析成區塊；原始碼模式下的編輯一律使用瀏覽器原生的復原功能（與區塊模式的 `Ctrl+Z` 分開）。
  - 右上角「複製原始碼」按鈕（複製圖示）：不管目前在區塊模式或原始碼模式，一鍵把整篇筆記目前的 Markdown 原始碼複製到剪貼簿。
  - **貼上多行內容自動拆成區塊**：從其他地方複製一段多行文字（例如含 `#` 標題、`-` 清單的 Markdown 內容）貼到編輯區時，系統會依照筆記支援的 Markdown 語法自動拆解成對應的標題／清單／表格／段落等區塊，而不是整段黏在同一個區塊裡；貼在空白區塊上會直接取代該空白區塊，貼在已有內容的區塊上則接在該區塊後面插入。單行的純文字貼上則維持瀏覽器原生行為，直接插入游標處。
  - 編輯內容會自動於背景儲存回本機的 `.md` 檔案。
  - 表格（GFM `| ... |` 語法）會正確渲染成真正的表格，每個儲存格可直接點擊編輯文字（含粗體/斜體等行內格式），欄位對齊依分隔列的 `:---`/`---:`/`:---:` 呈現，寬度一律撐滿至與標題/段落文字相同的右邊界（不會因內容較短而比其他區塊窄）。
    - **新增表格**：滑鼠移到任一區塊上點擊「Aa」格式按鈕，選「表格」即可把該區塊轉成一個 2×2 的空表格（若該區塊原本有文字，會保留在第一格）。
    - **新增/刪除列欄**：表格最後一列下方有「+ 新增列」；表頭最後一欄右邊有「+」新增欄；每個資料列前面、每個表頭儲存格右上角都有一顆「×」可刪除該列/欄（表頭本身不能刪，欄位至少會保留 1 欄）。
    - 儲存格之間可用 `Tab` / `Shift+Tab` 左右移動；在最後一格按 `Tab` 會自動新增一列並移入。
    - 儲存格內按 `↑` / `↓` 會移到同一欄的上一列 / 下一列（表頭列也算一列）；在表頭列按 `↑`，若表格前面已有其他區塊（含前一次按 `↑` 新增出來的空白段落），會移到該區塊；若表格已是最前面的區塊，則新增一個空白段落並移過去。在最後一列按 `↓`，若表格後面已有其他區塊（含文件最底下自動渲染出的可編輯空白段落），會移到該區塊；沒有的話則不會有反應。
    - 儲存格內的 `Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`）跟區塊模式共用同一套復原機制，可連續復原多步，新增/刪除列欄也算在復原範圍內。
    - 表格儲存格內僅支援單行文字與行內格式，不能在儲存格裡再放清單、標題等其他區塊。
  - **插入圖片**：三種方式擇一——直接貼上剪貼簿裡的圖片（`Ctrl+V`）、把圖片檔案拖放到編輯區、或滑鼠移到區塊上點「Aa」格式按鈕選「插入圖片」（跳出檔案選擇視窗）。圖片會上傳並存成跟目前這篇筆記**同一個資料夾**下的檔案（不建立額外的附屬資料夾），檔名沿用原始檔名，若同資料夾已有相同檔名會直接覆蓋（後蓋前，需自行留意檔名是否會撞名）。僅接受 `png`／`jpg`／`jpeg`／`gif`／`webp`，單檔大小上限 10MB。滑鼠移到圖片上會出現「×」可刪除該圖片區塊（僅移除筆記裡的參考，不會刪除磁碟上的圖片檔案）。插入圖片時若後面沒有其他文字區塊，系統會自動補一個空白段落並把游標移過去，讓你可以直接接著打字。
  - **程式碼區塊**：滑鼠移到區塊上點「Aa」格式按鈕選「程式碼」，即可把該區塊轉成一個淡色背景、等寬字型的程式碼區塊（保留原本的文字內容）。內容區可直接輸入/貼上多行程式碼、保留縮排與換行，高度會隨內容自動增高。編輯焦點在區塊內時，右上角會出現一個語言下拉選單（純粹當作標記，目前沒有語法高亮效果；離開焦點後會自動隱藏），可選擇常見語言（JavaScript／Python／SQL…等）；若筆記檔案裡原本存的語言標記不在清單內，仍會保留顯示，不會遺失。清空內容後按 `Backspace`，或滑鼠移到區塊上點右上角的「×」可刪除整個程式碼區塊。`Ctrl+Z`/`Ctrl+Shift+Z` 跟其他區塊共用同一套復原機制。
    - 在程式碼區塊最後一行按 `Enter`：第一次會像一般程式碼編輯器一樣新增一個空白行，讓你繼續寫多行程式碼；若該空白行沒有輸入任何內容就再按一次 `Enter`，系統會把這個多餘的空白行拿掉、跳出程式碼區塊，並在下方新增（或移到既有的）一般段落讓你接著打字。
  - **提示框／標註框（callout）**：滑鼠移到區塊上點「Aa」格式按鈕選「提示框」，即可把該區塊轉成一個帶顏色背景的提示框（預設種類為「備註」）。排版比照待辦清單項目：種類圖示固定顯示在左側，內文緊接在圖示右邊、可佔滿剩餘寬度並自動換行/支援多行。種類下拉選單顯示在區塊右上角，比照程式碼區塊的語言選單，只在編輯焦點位於該提示框內（內文或選單本身）時才顯示，可隨時切換 5 種種類：備註／提示／重要／警告／注意，各自有對應的顏色與圖示（顏色採用 GitHub 實際使用的配色）。內文支援粗體/斜體/刪除線/醒目提示/行內程式碼/連結等行內格式，也會被 `Ctrl+F` 搜尋/取代納入範圍；按 `Enter` 只會在同一個提示框內插入換行（不會分割成新區塊），清空內容後按 `Backspace`，或滑鼠移到區塊上點右上角的「×」可刪除整個提示框。儲存的 Markdown 語法採用 GitHub Flavored Markdown 的 Alerts 慣例（`> [!NOTE]`／`> [!TIP]`／`> [!IMPORTANT]`／`> [!WARNING]`／`> [!CAUTION]`，接續的 `> ` 開頭行為內文），與一般引用區塊共用 `>` 前綴、但以 `[!種類]` 標記區分。
  - **文件最底下若是圖片／程式碼區塊／表格／提示框**：編輯區固定會多顯示一行空白、可直接點擊輸入的段落，不需要按鍵、也不需要等程式自動移動游標——直接點擊該處打字即可接續編輯。這個空白段落只在畫面上輔助編輯，只要你沒有實際輸入任何內容，存檔時就不會留在 `.md` 檔案裡；一旦輸入了內容，就會變成正式段落一併存檔。
  - **在表格／圖片／程式碼區塊／提示框上方插入空白段落**：這四種區塊本身沒有游標可以按 `Enter` 加空行，滑鼠移到區塊上時，區塊正上方會浮現一個「+」按鈕，點擊即可在該區塊前插入一個空白段落並把游標移過去——最常見的用途是兩個表格緊接在一起時（Markdown 表格語法會把連續的表格行視為同一個表格），用這個按鈕在中間補一行空白，讓兩個表格存檔後仍是兩個獨立的表格，不會被誤判合併成一個。
- 開啟一篇筆記後，網址列會記錄該筆記的路徑；重新整理頁面會自動展開對應資料夾並恢復到原本開啟的那篇筆記。

## 已知限制

- 大綱區塊對應標題、清單（含巢狀）、表格、圖片、程式碼區塊、提示框、一般段落等 Markdown 語法；若筆記檔案
  含有其他尚未支援的 Markdown 語法，載入時會以純文字段落顯示，儲存時
  原樣保留內容，但不會被區塊化編輯。
- 表格目前無法從編輯器裡直接刪除整個表格區塊，也沒有欄位寬度拖曳調整、沒有「插入列/欄」（只能在最後新增一列/一欄）；要移除整個表格或調整既有列/欄順序，暫時只能切到「檢視原始碼」手動編輯 Markdown。表格儲存格內僅支援單行文字與行內格式，不能在儲存格裡再放清單、標題等其他區塊。
- 程式碼區塊（三個反引號 ` ``` ` 圍住的整段內容，跟行內程式碼格式 `` `像這樣` `` 是不同的東西，行內程式碼不受影響）目前沒有語法高亮，語言下拉選單只是單純的標記紀錄；`Tab` 鍵在程式碼區塊內是瀏覽器預設行為（把焦點移到下一個可聚焦元素，不會輸入縮排字元）；開頭/結尾的圍欄記號那一行必須整行只有 ` ``` `（後面最多接語言標記），前後夾雜其他文字則不會被辨識成程式碼區塊，仍當一般段落處理。
- 圖片存在跟筆記同一個資料夾，不是獨立附屬資料夾；「搬移」筆記到別的資料夾時，圖片檔案不會跟著搬（筆記裡的圖片參考會失效），「刪除」筆記也不會一併刪除同資料夾的圖片（沒辦法確定圖片是否被同資料夾其他筆記共用），需自行清理。未來規劃：搬移/刪除含圖片的筆記時跳出確認提示，告知圖片會一併搬移/刪除（沒有「只搬筆記、留下圖片」這種選項，只能選擇繼續或取消），目前尚未實作。
- 圖片區塊本身沒有可輸入文字的游標，沒有「按 `↑` 在上方插入空白段落」這種方向鍵快速操作（表格/程式碼區塊有）；不過現在滑鼠移到圖片上時，圖片正上方會出現「+」按鈕，一樣可以插入空白段落，不需要切到「檢視原始碼」。
- 用「+」按鈕在兩個相鄰表格之間插入的空白段落，只在「這次編輯」與「下一次存檔」之間確實有效（存檔後檔案裡會有一個真正的空白行，讓兩個表格維持獨立）；但空白行本身重新載入時不會還原成一個空白段落區塊（Markdown 解析空白行只會重置清單縮排狀態、不會建立區塊），所以切換筆記再切回來之後，兩個表格會變回直接相鄰、沒有間距（本質上仍是兩個獨立的表格，不會馬上合併）。如果在那之後又做了其他編輯觸發自動存檔，這次存檔會用「已經沒有空白段落」的狀態覆寫檔案，下次再重新載入就有可能讓兩個表格重新合併回一個——如果遇到這種情況，重新點一次「+」按鈕補回空白段落即可。
- 貼上多行內容時只讀取剪貼簿的純文字（`text/plain`），依本專案支援的 Markdown 子集規則解析成區塊；來源如果是網頁或 Word 等透過剪貼簿 HTML 呈現的粗體/顏色/字級等格式，不會被保留，只有貼上的純文字內容本身若剛好符合本專案的 Markdown 語法（例如 `**粗體**`、`# 標題`、`- 清單`）才會被辨識。
- 不提供跨筆記的全文搜尋（需要建立索引），只有 `Ctrl+F` 這種侷限在「目前這篇筆記」內的搜尋/取代；也不提供版本歷史、多人協作等功能。
- `Ctrl+F` 搜尋/取代的範圍涵蓋一般段落、標題、清單、引用、程式碼區塊與提示框，但不含表格儲存格與圖片替代文字。程式碼區塊內的符合結果因為輸入元件本身的限制（`<textarea>` 不支援內嵌標記），無法像其他區塊一樣用色塊同時標示「所有」符合結果，跳轉到程式碼區塊裡的符合結果時，會改用橘色外框標示整個程式碼區塊（不會把編輯焦點移進去，避免在搜尋框打字時焦點被意外轉移）。
- 提示框內文的方向鍵上下移動沒有比照表格/程式碼區塊做「移到邊界時跳出至相鄰區塊」的特殊處理，維持瀏覽器原生的游標移動行為；要離開提示框，可清空內容後按 `Backspace` 刪除該區塊，或直接點擊筆記其他地方。
- 浮動工具列已移除自訂文字大小（原本的「小/一般/大/特大」四級字級調整）的功能，改由「一般文字／標題 3／標題 2／標題 1」四級大小涵蓋——標題會連同區塊型態一起轉換，比單純調整選取文字大小更符合「整理筆記結構」的實際需求，也不會再有「選取範圍局部套用固定字級」跟「整個區塊轉標題」兩種放大手段互相衝突的問題。舊筆記若原本就含有字級調整（`<span style="font-size:...">`），仍會正常顯示；只是編輯器不再提供入口建立新的字級調整。
- 上述舊筆記裡殘留的字級調整，若使用者透過浮動工具列或「Aa」選單把該範圍所在區塊轉換為標題，系統會一併清除該字級調整（避免標題文字大小不一致），但轉換為其他型態（引用、清單等）不會清除。
- 醒目提示是以 `==文字==` 語法存進 `.md` 檔案，這是部分 Markdown 方言（例如 Obsidian）支援的
  慣例語法、非 CommonMark 標準核心語法；用不支援這個語法的檢視器開啟，會直接看到原始的 `==` 符號。

## Windows 7 相容性

本專案的相依套件（Flask 2.0.3 及其依賴）皆為純 Python 實作、無需編譯，已在實際
Windows 7 機器上安裝並實際使用中，確認可正常運作。前端圖示大多為手繪
的單色線條 SVG（不使用任何表情符號），避免在缺乏完整彩色表情符號字型的舊瀏覽器
上顯示成黑白線框或方框；例外是「新增資料夾」「新增筆記」（含資料夾選單「新文件」，
`static/img/new-folder.png`／`static/img/new-note.png`，背景已去除為透明）與樹狀
索引裡每個節點的資料夾/筆記圖示（`static/img/folder.png`／`static/img/note.png`，
依同樣的全彩風格另外繪製、不含右下角的「+」），這幾個圖示是一般 PNG 點陣圖，不
依賴表情符號字型，Win7 舊瀏覽器顯示上沒有相容性疑慮，但視覺風格跟其餘單色圖示
不一致（無法用 CSS 套色），此為使用者明確要求保留的例外。
