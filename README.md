# 本機知識筆記編輯器

本機可執行的知識整理工具：左側樹狀索引瀏覽本機筆記資料夾，右側以類似 Outline
的大綱式編輯器撰寫內容，所有筆記以 Markdown（`.md`）純文字格式儲存在本機檔案
系統，不需要網路連線，也不含全文搜尋功能。

## 系統需求

- Python 3.8（Windows 7 上官方最後支援的 Python 版本；本專案的相依套件皆為
  純 Python 實作，不需編譯，理論上可在更新的 Python 版本上執行）。
- 現代瀏覽器（Chrome、Edge、Firefox 等，含可於 Win7 上安裝的版本）。

## 安裝

```bash
cd notes-editor
pip install -r requirements.txt
```

## 啟動

```bash
python app.py
```

啟動後於瀏覽器開啟 `http://127.0.0.1:5000`。伺服器僅綁定在
`127.0.0.1`（僅本機可存取），不會對外部網路開放。

## 筆記根目錄設定

- 預設使用專案目錄下的 `notes/` 資料夾，若不存在會自動建立。
- 可透過環境變數 `NOTES_ROOT` 指定其他路徑：

```bash
set NOTES_ROOT=D:\MyNotes
python app.py
```

- 可透過環境變數 `PORT` 指定其他埠號（預設 `5000`），方便在同一台機器上另外開一個測試用的執行個體，不會跟正在使用的既有伺服器衝突：

```bash
set PORT=5051
python app.py
```

## 操作說明

- **左側樹狀索引**：點擊資料夾可展開/收合，並將其設為「目前操作目標」；
  點擊上方「📁+」「📄+」按鈕會在目前選取的資料夾下新增資料夾或筆記。
  滑鼠移到節點上時，最右側會出現「⋮」按鈕，點擊可開啟重新命名／搬移／刪除選單；也可直接按住節點拖曳到某個資料夾上放開，快速搬移過去（拖曳資料夾到它自己的子資料夾底下會被拒絕並提示錯誤），或拖到樹狀索引的空白處放開，搬回最外層。同一層級中資料夾一律排在筆記檔案前面；資料夾右側若底下（含子資料夾）有筆記，會顯示筆記總數的徽章。
- **右側編輯區**：點擊筆記節點後於右側編輯。
  - `Enter`：依游標位置切開目前區塊的文字（含粗體/斜體等行內格式）。游標在文字最前面時，會在目前區塊**前面**插入一個新空白區塊，原內容與子項目不受影響；游標在文字結尾或中間時，游標後面的文字（若有）會移到**後面**新插入的區塊，原區塊保留游標前的文字與所有子項目（一般清單／編號清單／待辦清單會延續同型態）。
  - `Tab` / `Shift+Tab`：將區塊縮排為子項目 / 取消縮排。
  - `Backspace`（區塊內容為空時）：刪除該區塊。
  - `↑` / `↓`：將游標移到上一個 / 下一個區塊（依樹狀展開順序，摺疊的子項目不會被跳到）。
  - `Ctrl+↑` / `Ctrl+↓`：將區塊本身上移 / 下移（調整順序，游標留在原區塊）。
  - 點擊區塊左側的摺疊箭頭：摺疊 / 展開子項目。
  - 在區塊開頭輸入 `#`～`######` 加空白：將該區塊轉換為對應層級的標題。
  - 滑鼠移到區塊上會出現「Aa」格式按鈕，可切換標題 1/2/3、引用、編號清單、待辦清單、一般文字。
  - `Ctrl+Alt+1` / `Ctrl+Alt+2` / `Ctrl+Alt+3`：將目前區塊設為標題 1/2/3；`Ctrl+Alt+0`：還原為一般文字。
  - 待辦清單項目可直接點擊前方核取方塊切換完成狀態（完成後套用刪除線樣式）。
  - 選取一段文字時會出現浮動工具列，可套用粗體、斜體、刪除線、行內程式碼、連結；也可用快捷鍵 `Ctrl+B` / `Ctrl+I` / `Ctrl+Shift+X`。
  - 浮動工具列的「A」按鈕可調整選取文字的大小（小/一般/大/特大），只影響選取的那段文字，不像標題是整個區塊放大。
  - `Ctrl+Z`：復原上一步修改，可連續復原到剛開啟此筆記時的狀態；`Ctrl+Shift+Z` 或 `Ctrl+Y`：取消復原。復原/取消復原的範圍僅限於目前開啟的這篇筆記，切換到其他筆記後會重新計算。
  - 右上角「檢視原始碼」按鈕：切換為可直接檢視、貼上、編輯完整 Markdown 原始碼的模式，切回區塊模式時會重新解析成區塊；原始碼模式下的編輯一律使用瀏覽器原生的復原功能（與區塊模式的 `Ctrl+Z` 分開）。
  - 右上角「複製原始碼」按鈕：不管目前在區塊模式或原始碼模式，一鍵把整篇筆記目前的 Markdown 原始碼複製到剪貼簿。
  - 編輯內容會自動於背景儲存回本機的 `.md` 檔案。
  - 表格（GFM `| ... |` 語法）會正確渲染成真正的表格，每個儲存格可直接點擊編輯文字（含粗體/斜體等行內格式），欄位對齊依分隔列的 `:---`/`---:`/`:---:` 呈現，寬度一律撐滿至與標題/段落文字相同的右邊界（不會因內容較短而比其他區塊窄）。
    - **新增表格**：滑鼠移到任一區塊上點擊「Aa」格式按鈕，選「表格」即可把該區塊轉成一個 2×2 的空表格（若該區塊原本有文字，會保留在第一格）。
    - **新增/刪除列欄**：表格最後一列下方有「+ 新增列」；表頭最後一欄右邊有「+」新增欄；每個資料列前面、每個表頭儲存格右上角都有一顆「×」可刪除該列/欄（表頭本身不能刪，欄位至少會保留 1 欄）。
    - 儲存格之間可用 `Tab` / `Shift+Tab` 左右移動；在最後一格按 `Tab` 會自動新增一列並移入。
    - 儲存格內的 `Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`）跟區塊模式共用同一套復原機制，可連續復原多步，新增/刪除列欄也算在復原範圍內。
    - 表格儲存格內僅支援單行文字與行內格式，不能在儲存格裡再放清單、標題等其他區塊。
- 開啟一篇筆記後，網址列會記錄該筆記的路徑；重新整理頁面會自動展開對應資料夾並恢復到原本開啟的那篇筆記。

## 已知限制

- 大綱區塊對應標題、清單（含巢狀）、表格、一般段落等 Markdown 語法；若筆記檔案
  含有程式碼區塊等其他尚未支援的 Markdown 語法，載入時會以純文字段落顯示，儲存時
  原樣保留內容，但不會被區塊化編輯。
- 表格目前無法從編輯器裡直接刪除整個表格區塊，也沒有欄位寬度拖曳調整、沒有「插入列/欄」（只能在最後新增一列/一欄）；要移除整個表格或調整既有列/欄順序，暫時只能切到「檢視原始碼」手動編輯 Markdown。表格儲存格內僅支援單行文字與行內格式，不能在儲存格裡再放清單、標題等其他區塊。
- 不提供全文搜尋、版本歷史、多人協作等功能。
- 文字大小只提供 4 個固定級距（小/一般/大/特大），沒有自由調整像素數值的滑桿。
- 文字大小是以內嵌 HTML（`<span style="font-size:...">`）存進 `.md` 檔案，一般 Markdown
  檢視器多半能正確顯示；但若用不支援內嵌 HTML 的檢視器開啟，會直接看到原始的 `<span>` 標籤文字。

```bash
python -m unittest discover -s tests -t .
```

## Windows 7 相容性

本專案的相依套件（Flask 2.0.3 及其依賴）皆為純 Python 實作、無需編譯，理論上
可在 Windows 7 + Python 3.8 環境下正常運作，但尚未在實際 Windows 7 機器上完成
最終安裝與啟動驗證，建議在正式導入前於目標機器上實測一次。
