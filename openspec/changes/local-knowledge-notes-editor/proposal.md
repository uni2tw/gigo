## Why

使用者需要一個完全在本機執行、不依賴雲端或外部服務的知識整理工具。現有的筆記軟體要嘛需要安裝重量級環境、要嘛不支援舊版 Windows（Win7），無法滿足在受限環境（如仍在使用 Win7 的機器）上離線整理與編輯 Markdown 筆記的需求。

## What Changes

- 新增一個以 Python 撰寫、可在本機啟動的網站應用（本機 Web Server + 瀏覽器介面），需相容 Win7 可執行的 Python 版本與套件。
- 新增左側樹狀索引：呈現本機資料夾內的筆記階層結構（資料夾/檔案），支援瀏覽、新增、重新命名、刪除、搬移節點。
- 新增右側線上編輯區：以類似 Outline（大綱式、區塊化）的編輯體驗撰寫筆記內容。
- 筆記內容一律以 Markdown（`.md`）格式儲存於本機檔案系統，樹狀結構直接對應本機資料夾/檔案結構。
- 明確不包含全文搜尋功能（Out of scope）。

## Capabilities

### New Capabilities
- `note-tree-navigation`: 左側樹狀索引，讀取本機筆記資料夾結構並支援新增/重新命名/刪除/搬移節點。
- `outline-note-editor`: 右側大綱式（outline-style）線上編輯器，供使用者編輯筆記內容。
- `markdown-file-storage`: 將筆記以 Markdown 檔案格式讀寫於本機檔案系統，作為樹狀索引與編輯器的資料來源。

### Modified Capabilities
（無，此為全新專案，尚無既有 spec）

## Impact

- 新增獨立的 Python 專案（與 `PXB2E.*` 系列 .NET 專案無關），需在本機以 Python 啟動一個輕量 Web Server。
- 需選用能在 Win7 上執行的 Python 版本（例如 Python 3.8 為官方最後支援 Win7 的版本）與相容的最小依賴套件組合。
- 前端需實作樹狀元件與大綱式編輯器（區塊縮排、上下移動、摺疊/展開等操作）。
- 新增對本機檔案系統的讀寫邏輯（建立/重新命名/刪除/搬移資料夾與 `.md` 檔案），需留意路徑安全性（避免跳脫指定的筆記根目錄）。
- 不涉及任何資料庫、外部 API 或雲端服務；不實作搜尋功能。
